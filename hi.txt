- Employee

Most of current setup is for HR, but for employe we need a self service mechanism + approval mechanism only.

Employee Mode
After analysis if the entitlement needs no approval, the access will be provided then and there. 
Else if it needs approval, the bot will ask the employee if he wants to send the request to his manager.
The employee setup will also have a request approval section(because this employee might be some other employee's manager), where employee can see approvals - he may approve or reject.
If the manager approves, the access is granted, otherwise the message of refusal is sent to employee.

HR Mode 
After analysis, if entitlements need no approval, then the entitlement is granted then and there.
Else if approval needed, the request is sent to manager of new joiner directly.
If the manager approves, the access is granted, otherwise the message of refusal is sent to HR.
